Support

We answer within two working days.

Questions, a problem with the app, or a server that does not connect? Write to us — please mention your iOS version and the Odoo version of your server.

Write to hi@sftmchn.tech

Adding a server

Tap “+” and enter the address you use to open Odoo in a browser, for example erp.example.com. Without a scheme the app uses HTTPS; for a server without a certificate type the full address with http://.

Opening the server list again

Swipe from the left edge of the screen, or choose “Server” in your profile menu when the server has the companion module installed.

Push notifications

Notifications work when the server has the companion module for mobile clients installed and an Apple push key configured by your administrator. Without it the app still works; only notifications are missing.

Removing your data

Swipe a server to the left in the list and tap Delete: its session and push registration are removed. Deleting the app removes everything stored on the phone. Data on the server itself is managed by the server's owner.
